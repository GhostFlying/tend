# Generated: owner API types

Do not edit these files by hand.

- `api.ts` holds the TypeScript types of the owner API, generated by
  [json-schema-to-typescript](https://github.com/bcherny/json-schema-to-typescript)
  from `internal/protocol/generated/api.schema.json`, which is in turn
  generated from the Go types in `internal/protocol` (D22).

  ```sh
  make gen          # Go types -> api.schema.json (repository root)
  cd web && pnpm gen  # api.schema.json -> api.ts
  ```

  `scripts/genapi.test.ts` fails when the committed `api.ts` no longer
  matches the schema.
