# 测试准备精简的目标测量与检错验证

Refs: D151。只精简重复业务准备，保留完整检查与现有业务测试根；未重新引入自动选测方案。完整检查的前后墙钟、CPU及当前CI状态统一记录在 [PR #241 的验证部分](https://github.com/GhostFlying/tend/pull/241)，不从下列目标根耗时推算整轮收益。

## 改动及覆盖边界

- 看板仍有231条数据、七种生命周期、项目和组合筛选、相同时间戳及分页/非法输入。保留一次真实创建，从其任务/spec/action/Issue所有权投影，在同一准备事务内插入其余数据；新增返回生命周期和项目的核对。
- 关系仍有150条双向关系，保留次序/身份、排队执行事实、全队列扫描恰好一次、查询数量上限及真实claim。保留根的真实创建和关系更新命令，批量准备相关任务投影。
- `TaskSeed` 仅用于读取和排队投影，副本属于同一Issue，不伪造创建请求、事件或outbox；它不适用于创建、Issue流程或完整历史验证。各复用变体仍有独立数据库、时钟、ID、runner实例与工作区；每个目标根的测量使用独立测试进程。
- AppServer与Orca的完整配置拒绝、reload、restart、冻结定义和独立验收断言保留。复用变体准备真实完成的来源，去掉重复的完整配置/重启检查，保留显式和默认复用入口、资源释放、缺reviewer拒绝claim及恢复后完成；增加workspace身份和旧Run pin不变的核对。
- 放置权重仅更新三个变化根的经验提示，继续动态发现所有根；权重不决定测试选择。

## 固定源码和目标根测量

基线 `bc2be98a8e1e735f2d506195f0ecddf14ce91408`，实现 `9b34d09a11d0c3f07151b9766dd1196950b2e76e`。同一开发环境，Go 1.27.1、Linux amd64，每个race测试进程GOMAXPROCS=2、编译包并行2。每包编译一次带race的测试二进制，各根独立进程执行 `-test.count=1`；没有Go测试结果缓存，编译成本另列。机器64逻辑CPU，非独占；实际工具链、负载及用户/系统CPU时间见 JSON。每根一组前后测量，不宣称稳定百分比或CI收益。

| 目标 | 修改前秒数 | 修改后秒数 | 本轮墙钟变化 |
| --- | ---: | ---: | ---: |
| 看板分页 | 271.33 | 25.45 | 90.6% 减少 |
| 关系查询 | 126.50 | 14.12 | 88.8% 减少 |
| 完整 reload/restart 对照 | 18.26 | 18.90 | 3.5% 增加 |
| 显式与默认 workspace 复用 | 22.87 | 20.36 | 11.0% 减少 |

上述根的顺序墙钟合计 438.96 → 78.83 秒。完整reload/restart对照的微小变慢属于本轮观察；未改变它的业务断言，不将其包装为加速。并行完整检查的墙钟由最长分组决定，不能将目标节省相加后当作整轮收益。

完整检查前统一准备race构建缓存及Web依赖，两侧均 `TEST_COUNT=1`；默认日常入口仍保留原生Go缓存。全量前后在独立源码副本中顺序运行，完整集合、失败记录和Go源码身份单独核对；最终记录见上述PR。

## 真实故障注入

在独立副本中逐次恢复干净源码，只改一个生产文件并运行保留测试。要求目标根实际run、fail，且出现对应业务断言；编译失败或其他测试失败不能充当检错证明。故障没有带入提交。

| 故障 | 保留测试实际检出的断言 |
| --- | --- |
| `page-200-truncation` | `listed 200 tasks, want 231` |
| `lifecycle-filter` | `unexpected or duplicate task` |
| `cursor-ties` | `unexpected or duplicate task` |
| `relation-queue-n-plus-one` | `whole-queue scans, want one` |
| `relation-truncation` | `relations 100, want 150` |
| `reused-first-reviewer` | `new reused task claimed without an eligible reviewer` |

六项全部检出；原生顶层run/fail事件、工具源码与日志摘要保留于[机器可读证据](test-setup-deduplication.json)。关系N+1故障运行约131秒，因为故意重复扫描；这不是正常路径的收益测量。
