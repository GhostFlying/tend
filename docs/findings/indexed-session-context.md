# 索引交接的静态上下文评估

Refs: D196。本报告只比较上下文构成，不把输入下降比例当作账单节省。

## 方法

使用已有托管会话样本的首次原生请求 usage，扣除当时注入的 handoff 和正常首轮上下文正文，加入新索引、正常上下文 formatter 的输出及新工具定义。新正文使用实际代码中的模板和 `ContextIndexText`，JSON 编码与生产一致；状态计数、事件水位及 assignment epoch 使用代表值，数值长度可能带来小幅偏差。用本地 o200k_base 计数作差量近似，额外预留 30 tokens 用于 rollout thread 选择器和信封差异；它不是运行时模型 tokenizer 的精确重放。

全部固定角色提示、原生基础提示、已有工具定义、memory/skills、当前消息与准入元数据保留。未发起新的模型请求，也未测量真实恢复后的净费用。

## 结果

| 样本 | 原首次输入 tokens | 新首次输入估计 | 减少 |
|---|---:|---:|---:|
| Main A | 30,881 | 17,299 | 44.0% |
| Main B | 28,597 | 17,808 | 37.7% |
| Main C | 30,659 | 18,018 | 41.2% |
| Issue A | 209,394 | 27,505 | 86.9% |
| Issue B | 218,694 | 27,804 | 87.3% |

另一个 Main handoff 尚无首轮业务请求，不能估计其完整首轮。咨询没有同类历史样本，不外推比例。

交接索引样本为 1,017–1,090 字节、239–272 tokens；正常上下文索引为 928–1,062 字节、191–250 tokens。新增 context-index 工具定义的离线计数为约 172 tokens。自动注入的两个入口各自强制限制在 2 KiB，历史正文再长也不改变上限。

## 按需读取与证据边界

- 查状态：context-index 默认 state，仅返回当前身份、版本、状态及数量，不附带来源、事实或合同正文。
- 恢复约束：分页获取来源/事实引用后，以原 ID 查询既有材料接口；当前继承资料及原文仍可访问，不将全部继承正文复制到自动提示。
- 继续审阅：保留原准入和 context revision 绑定。Issue 的 turn/source/context review 及 commit 仍校验原版本；索引读取不推进审阅状态。咨询通过自身对话工具恢复当前输入，不能读取 Main 或其他会话。

对应回归使用大正文、55 条以上来源、原文更正/撤回、继承上下文及实际托管工具回调，验证有界索引、分页和隔离。它们验证机制，不证明模型会选择最省 token 的查询路径。按需查询的输入、输出、工具轮次和后续反复携带的内容，需要后续真实运行再观察。

删除 Tend 摘要生产后，其维护模型 turn 为零；该收益独立于上述首轮差量。显式手动 compact 与运行时自身行为不属于这项归零统计。
