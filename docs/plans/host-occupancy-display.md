# 执行主机占用显示修正

问题：主机列表用灰点表示零个 run，容易被误读为离线。当前 HostView 仅提供配置为 active 的主机和槽位占用，没有实时在线状态；不新增未经证实的在线指示。

1. 移除主机行的状态点，以文字区分“空闲”和“执行中”，保留已用 / 总槽位，明确这是占用情况。
2. 保持任务状态点、接口和调度语义不变；复用现有排版，核对手机窄屏及深浅色下的显示。
3. 完整检查、独立 review、CI、PR 合入及部署后读回；使用浏览器 fixture 检查空闲与执行中，线上只读检查真实主机。Browser plugin not available，使用 Playwright。
