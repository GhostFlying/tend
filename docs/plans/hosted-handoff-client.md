# 托管主会话交接的客户端接入

Refs: D81，主计划 hosted-toolset-upgrades.md。

Web 在侧栏底部设置入口及手机聊天/看板顶部设置图标打开 Shell 层共享轻量设置面板，在主 agent 区展示预备摘要，显示当前/过期摘要、待处理状态与空闲分钟设置；0 关闭后台摘要，1..10080 分钟可配置。读取、独立 revision 保存、跨设备事件刷新及不确定结果核对不依赖模型目录。关闭菜单或重连不得生成重复写请求，读取失败保留已有状态并有限退避重试。提供立即生成预备摘要操作；立即交接仍仅在 CLI。保持模型和思考强度控件原有语义。

CLI 增加 conversation handoff [--prepare-only] 和 handoff --status，复用 owner 请求身份与错误处理。服务端 main_agent.summary_idle_minutes 缺省为 50、0 关闭、限制 0..10080；产品始终启用交接维护，并注入时钟。同步部署说明与示例。

验证独立 revision、stale 重读、unknown 仅核对、跨设备刷新与读取取消；CLI owner 鉴权/同 ID 网络重试/unknown 不新请求，配置缺省及边界；生产构建的桌面与手机浅深色、键盘焦点、菜单及错误恢复。Browser plugin not available，使用现有 Playwright，无新依赖。临时服务和浏览器始终清理；不部署或提交。

评审修正：消息、新流式正文、工具结果和消息状态事件立即使本地摘要 current=false，内容更新期间合并每秒最多一次状态核对；读取中的旧响应不得重新点亮最新状态。保留摘要生成、设置和交接完成事件的立即刷新，关闭连接取消待刷定时器。覆盖新消息、同 seq 流式更新、迟到快照和连续输出不产生 GET 风暴。

维护状态修正：操作排队成功不等于摘要完成。立即准备请求受理后保持本地等待标记，重新读取并短轮询 pending/preparing 或维护 pending/sending；维护记录可见后交由服务端状态控制，failed/unknown 显示原因并停止忙轮询。防止更早启动的读取清除受理后的等待状态。CLI status 同步展示维护结果。
