2. 扩展角色化字号、间距、圆角、层级、控件高度与双主题语义色；对现有 CSS 和内联样式做等价或就近映射，保持布局和业务行为。

## 实施说明

- 基础字号按角色迁移并移除旧别名；保留额外的 20、24、28、32px 展示字号及原有 2、5 层级的命名 token，避免既有文字或堆叠顺序发生超出本片范围的变化。
- 新控件集中在 `web/src/ui/`；仅原 controls 的使用点迁至 Button 与 EmptyState，事件处理、提交类型与业务状态保持原样。既有详情与任务页 tabs 留待后续页面分片采用新的 Tabs。
- 样式检查覆盖全部源 CSS（唯一原值定义例外为 tokens），同时检查字体简写与单角圆角；输出违规所在文件与行号。
- 截图和浏览器交互探针保存在仓库外，使用既有合成夹具，分别覆盖桌面和手机。所有既有业务脚本及业务断言保持不变。

## 第一轮验收修正计划

1. 修正决定布局夹具的字号缩放：同步缩放角色字号和行高，在布局矩阵调用处校验 body 实际字号，防止 token 重命名后静默失效。
2. 扩展样式检查到 CSS 颜色函数与命名颜色，排除变量名、URL、字符串与字体族；迁移剩余裸颜色并补充规则测试。
3. 定位拒绝回答后的焦点竞争：记录恢复时的按钮禁用状态和渲染时序，在产品中将恢复绑定到已提交的可用状态，同时保留用户主动移动焦点时的行为。保留并补充浏览器断言，决定布局连续至少六轮通过。
4. 重跑全部 Web 门禁及所有 test 脚本，保存本轮日志与截图，再创建带 D132 / S1 引用的独立修正提交。

## 第一轮修正实现

- 时序探针在原实现上复现：错误提示已提交，但 busy=false 的 React DOM 更新尚未提交，rAF 已调用仍禁用的按钮；禁用状态约两毫秒后才清除。新的 layout effect 将恢复绑定到可用 DOM，主动移到消息输入框的焦点仍保留。决定布局保留原有三秒断言，并加入拒绝后首个帧提前运行的时序探针。
- 字号夹具从根计算样式读取所有角色字号和行高；矩阵同时记录 bodyFontSize 并校验缩放比例。
- 颜色检查覆盖 148 个 CSS 命名颜色及各类颜色函数；屏蔽注释、字符串和 URL，忽略变量名与字体族，但检查变量 fallback 与渐变中的裸色。iframe 纸面和渐隐遮罩分别使用双主题固定白色、固定黑色语义 token。
