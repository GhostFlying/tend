# 统一用量计价的模型名大小写归一化

Refs: D117、D176。

## 目标与边界

统一计价器接受模型名的大小写差异，所有 Agent、职责与采集入口共用，不增加角色分支。保留原始模型名、原生请求身份、Token 计数与归属；价格仍是当前公开目录的估算。

## 实施

1. 完整目录 ID 的原样精确匹配优先；没有精确结果时，按不区分大小写的完整 ID、唯一模型 slug 顺序解析。任一层出现多个候选均保持未报价，不猜测供应商，不混同 batch 等模型变体。
2. 追加迁移，将现有请求统一登记到原有投影待处理队列。服务启动沿 D176 的既有流程重新解析模型并重算贡献与汇总，使新旧记录使用相同规则；不修改事实、不重采历史、不新增定时器或管理入口。
3. 更新 D117 的匹配约定；API、CLI、Web 与 runner 协议不变。

## 验证与交付

覆盖大小写不同的完整 ID 与 slug、精确匹配优先、跨供应商及大小写冲突、未知模型、batch 变体和缺失计数。验证升级后历史未报价记录重新估算，原事实与计数保持不变，重复启动不重复排队。运行专项 race 测试、完整 make check、独立 review，提交可审查 PR；不部署。
