# 子 Issue 长标题布局修复

范围仅限看板子 Issue 的标题、状态与交互行布局；不修改直接子集合、计数、协议或交付机制。
复用原候选的局部样式和浏览器回归，按当前 main 重新验证，不继承旧候选的检查结果。

1. 核对通用 Button 的固定高度与看板子行换行约束，仅将子行高度改为自然高度。
2. 以隔离 API fixture 验证 390、360、320 和 1440 像素：长中英文标题、状态、
   行按钮及查看全部均在卡内，下一卡不重叠，无横向溢出，展开、刷新和末行点击正常。
3. 比较元素的完整几何在同一浏览器求值中采样，避免展开后的滚动锚定造成跨时刻误判；
   保留 containment、overlap、真实滚动及点击断言。
4. 同时运行既有直接子 Issue 进度入口，确保原集合和进度语义不受影响。
5. Web 检查、完整本地检查、独立 review 与 CI 按仓库并行流程执行。新候选通过 PR
   交集成责任合入；部署保持集中安排。本修复不改变设计决策。
