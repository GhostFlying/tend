# F7 停止请求恢复计划

复现：停止 HTTP 请求未送达时，仅保存消息 ID 会丢失请求身份，重连后按钮一直禁用。沿用 D11 和 D69，先持久化完整停止请求及 request_id，再投递。

恢复时先查询原 request：没有记录才允许使用相同 envelope 和 request_id 恢复 HTTP 投递；已有 accepted、succeeded 或 unknown 记录时，只查询既有请求及观察消息终态，不生成新的中断，也不重放外部副作用。明确拒绝后可再次操作。页面刷新保留请求身份，读取失败采用有限退避，组件退出时清理重试计时器。

补未送达重连、刷新后同 ID 恢复、已记录 unknown 不重发的回归与生产构建浏览器验证。同步阶段 F §4 和设计 D69 的文字，提交前运行 `make check`。
