# 移动端设置入口与执行主机可见性

## 目标与证据

移除任务看板和聊天页头的重复设置齿轮，保留侧栏（手机待处理页）底部文字设置入口及独立模型设置。改善执行主机的发现、状态阅读和详情访问，不修改登记、调度、租约或运行配置。

原附件已通过 attachments_read 读取并下载，原件保持不变。只读部署查询中 repos_list 与 owner snapshot 均返回两台主机；当前源码遍历完整 hosts 数组，项目过滤只影响任务。手机看板把最近完成和主机折叠区放进最高 180px 的共同滚动区；展开最近完成会把主机入口推出可视范围。需在浏览器用通用数据记录改动前后的几何与滚动证据，不能将本地 fixture 当作原手机操作的证明。

## 实施步骤

- M1：复现两台主机及最近完成展开时的入口和行可见性，检查 Sidebar 滚动、底栏和设置访问。
- M2：移除两处页头齿轮与无用回调；执行主机优先显示独立整行折叠入口与总数，列表内容有界纵向滚动，最近完成不能掩盖主机入口；保持任务看板的可用高度。补充侧栏滚动边界及手机设置触控尺寸。按 D70、D81、D85、D86 更新现有设计描述。
- M3：增加实际浏览器布局回归检查，覆盖 390px、430px 与桌面、零/一/多主机、离线与维护、两折叠区域同时展开、分别打开详情及实时快照变更、项目筛选、设置保存与关闭。验证手机与桌面导航，截图仅使用通用测试数据。
- M4：通过 make check 和仓库要求的独立 review；使用现有 Git 身份作原子提交，推送任务分支并创建 PR，不合并、不部署。报告区分部署 API 事实、本地浏览器复现与尚未确认的原手机行为，交付选定截图。

## 范围边界

不更改 owner API 或通信协议，除非证据证明存在本任务相关的数据缺陷。不硬编码主机身份或数量，不复制真实环境标识到公开代码、文档、截图、commit 或 PR。不访问或操作执行主机进程，不发送消息或评论。

## 可重复验证

`make check` 执行仓库原有完整检查。新增 `pnpm --dir web test:layout` 构建真实 Web 产物并在独立本地 HTTP 服务上运行 Chromium 布局检查，所有 API 均为通用测试数据；CI 安装 Chromium 后执行该检查。首次本地运行可用 `pnpm --dir web exec playwright install chromium` 准备浏览器。已有浏览器可通过 `TEND_LAYOUT_BROWSER` 指定，`TEND_LAYOUT_OUTPUT` 可指定仓库外的截图目录。浏览器系统字体需支持中文。

脚本覆盖两种手机宽度、桌面和较短手机屏幕；以实际点击命中和滚动检查识别裁切，而不只依赖 DOM 中是否存在主机。测试两台分别打开详情、24 台滚动到末项、零/一台及快照新增/重排、离线和维护、项目过滤、保留设置入口保存及恢复焦点。截图文件名包含视口，均为通用 fixture，不证明部署已经生效。

使用任务起始版本构建的 Chromium 对照（含中文字体）：390×760px 展开主机后共同区底部为 y=279，第一台在 y=201–267 完整可见，第二台在 y=267–335 被裁切且中心不可点击；430×760px 也只有第一台完整可见。展开五条最近完成时，390px 主机入口在 y=419–441，430px 在 y=415–437，均落在共同区可视边界之外。只读真实接口的两台主机与该浏览器复现是不同证据；尚未获得原手机的 DOM、滚动位置或点击过程，不能把其每一步操作归因写成已确认事实。
