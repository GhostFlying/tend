# S5 文案与术语实施计划

Refs: D131
Plan: S5

1. 统一 UI 自有文案的中英混排、主 Agent、Issue 和执行术语；用 TypeScript AST 扫描 JSX、字符串及模板片段，例外集中登记并说明原因。
2. 负责人使用目录显示名或负责人 Agent，头像取显示名；任务要求版本与优先级采用用户术语，紧凑行隐藏未评级。
3. 默认行、卡片与标题隐藏内部标识；详情折叠展示可复制标识，提交显示七位短哈希，系统发布通知采用人类可读摘要。
4. 登记工具动作标签；同轮连续完成工具折叠为组，运行与失败独立保留，展开仍能查看原始输入输出。
5. 复核收件箱与通知，保持 unknown、请求核实及回答合同；更新依赖文案的布局选择器而不删除业务断言。

文件范围：`web/src/i18n/`、`conversation/`、`issues/`、`tasks/`、`shell/Details.tsx`、`upgrades/` 及其它自有文案使用点；`web/scripts/` 仅调整相关选择器与补充截图探针。

测试：vitest 覆盖混排规则、工具映射及分组、短哈希、负责人名称；串行运行分片全部门禁。保存并人工检查桌面与手机浅色的工具聊天、任务、Issue、收件箱和发布截图。

非目标：不修改用户或 Agent 正文、Issue 标题描述、附件名称、生成类型、服务端、协议、存储与请求身份；不新增依赖，不改变导航、草稿、队列、任务控制或焦点恢复。
