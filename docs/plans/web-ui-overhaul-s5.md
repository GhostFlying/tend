# S5 文案与术语实施计划

Refs: D131
Plan: S5

1. 统一 UI 自有文案的中英混排、主 Agent、Issue 和执行术语；用 TypeScript AST 扫描 JSX、字符串及模板片段，例外集中登记并说明原因。
2. 负责人使用目录显示名或负责人 Agent，头像取显示名；任务要求版本与优先级采用用户术语，紧凑行隐藏未评级。
3. 默认行、卡片与标题隐藏内部标识；详情折叠展示可复制标识，提交显示七位短哈希，系统发布通知采用人类可读摘要。
4. 登记工具动作标签；同轮连续完成工具折叠为组，运行与失败独立保留，展开仍能查看原始输入输出。
5. 复核收件箱与通知，保持 unknown、请求核实及回答合同；更新依赖文案的布局选择器而不删除业务断言。

文件范围：`web/src/i18n/`、`conversation/`、`issues/`、`tasks/`、`shell/Details.tsx`、`upgrades/` 及其它自有文案使用点；`web/scripts/` 仅调整相关选择器与补充截图探针。

测试：vitest 覆盖混排规则、工具映射及分组、短哈希、负责人名称；串行运行分片全部门禁。保存并人工检查桌面与手机浅色的工具聊天、任务、Issue、收件箱和发布截图。

非目标：不修改用户或 Agent 正文、Issue 标题描述、附件名称、生成类型、服务端、协议、存储与请求身份；不新增依赖，不改变导航、草稿、队列、任务控制或焦点恢复。

## 首轮复核修正计划

1. 工具行展开或焦点位于回合内时保留分组边界，实时更新内容但不重新挂载；补充连续工具完成的浏览器探针，统一组标题与行的字体和箭头。
2. 全部任务执行入口采用任务执行列表中的固定序号，不用可重置的 generation 展示轮次；补充重复代次、要求更新的单元测试。
3. 待处理提出者按协议 run 身份与角色区分执行 Agent 和负责人 Agent，并补充测试。
4. 发布系统卡统一披露与链接间距；手机任务标签增加明确的滚动边缘提示，保存受影响截图并串行完成门禁。

## 第二轮复核修正计划

- 展开／聚焦期间只冻结既有分组边界，不冻结顺序。按当前 transcript 顺序插入补读消息，保持既有分组和控件的 key；补充跨页先收到第 61 项再补读第 51–60 项的单元测试。
- 串行运行完整分片门禁，不修改队列或分页合同。

## 第三轮复核修正计划

- 分组始终只容纳 transcript 中连续的工具调用；补读正文和选择卡必须拆开分组并独立展示。
- 拆分时仅让正在阅读的工具段保留原分组 key 和披露容器，其余段可重建；补充关闭分组内补读正文／选择卡及正在阅读后段的测试，串行运行全部门禁。

## 最终工具展示设计

- 删除延迟重分组、segment key 和 blur/focus 事件追踪。回合始终渲染按 transcript 排序的平坦列表，每条内容永久使用 `item:<id>`，工具、正文、选择卡均不进入分组容器。
- 连续已完成工具前插入独立的 `group:<首工具 id>` 切换按钮；折叠只设置工具行的 hidden，正文和选择卡永不隐藏。运行与失败工具独立展示。
- 分组展开状态由回合保存；成员正在展开或聚焦时保持可见。新成员集合先保持可见，在 layout effect 中核对阅读状态；补读改变首项时按成员交集继承展开状态，不改变任何内容节点 key。
- 单元测试覆盖固定内容 key、补读拆组、展开行可见及选择卡 key；保留工具完成时原 DOM 与焦点不变的浏览器断言，串行运行全部门禁。

## 显式折叠优先

- 成员展开／聚焦保护仅在工具组成员变化时启用。成员集合不变时完全服从组切换状态，显式折叠即隐藏所有工具行并聚焦组按钮；保留行内披露状态供再次展开阅读。
- 补充含已展开成员的显式折叠单元测试，并在桌面和手机浏览器探针验证成员隐藏和按钮焦点，串行运行门禁。
