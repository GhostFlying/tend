# 自适应并发分组

## 目标与约束

在 host slot 外增加服务端管理的共享并发预算。runtime 按执行环境与稳定 ID
绑定一组；所有执行方式共享计数，代理不重复计数。保留 runner claim、冻结负责人、
原生重试、journal、fencing 和 unknown 对账。未绑定执行保持原行为。
CLI 是完整管理入口，Web 只读，不增加配置文件。Refs: D142、D153。

## 控制规则

- 每组名称、min/initial/max；1 <= min <= initial <= max。创建取 initial，
  修改只截断当前值，重启保留学习值但重置稳定观察。
- 明确的临时 429/overload 每次减 1；30 秒内合并降档，最后拥塞后冷却 30 秒。
  同 attempt/turn 的重试与最终回执去重，最低值仍冷却。明确 quota/auth 不误判。
- 当前值不变的最近 30 分钟没有拥塞、累计满载至少 15 分钟、存在成功 turn、
  反馈完整且仍有符合要求的容量等待，才能加 1。每次调档重新观察。
  满载只计确认运行，排除预留、准备、空闲、unknown 与超过当前上限的收缩阶段。
- 成员变更、重启或反馈失联中断观察。迟到事件影响后续控制，不改写历史决策。

## 实施顺序

1. 追加迁移、公共协议与纯控制算法；账本管理分组、绑定、占用、反馈及满载区间。
2. claim 与托管准入同事务检查/预留；连接各 harness 反馈与执行停止证明，额外
   摘要独立申请，资源不足不阻塞父执行退出。旧 runner 按能力协商。
3. 实现 owner API 与 tend agents concurrency list/show/create/update/bind/unbind/
   delete/history；完整参数、JSON、筛选分页、CAS、dry-run/replay 与能力入口验证。
4. Agents 增加并发分组分类，展示配置、占用、学习进度和最近七天记录。
5. 完整检查、浏览器验证、独立 review；仅经 PR 交付，不自动生产部署。

## 历史与验收

最近滚动七天保留初始化、手工截断、自动升降档、下限冷却及所有合并反馈。
降档明确 Issue/任务/run/Agent/runtime/session/native thread/turn、结构化错误和
发生/接收时间；无 Issue 或缺 native ID 如实显示。升档保存窗口、满载毫秒数、
成功 turn 数、零拥塞、反馈完整性与等待数。保留决策时标题与配置快照。
历史清理不影响当前状态或去重。

可控时钟覆盖所有边界、重放/迟到事件、故障合并、跨 runner 原子准入、代理计数、
未知结果、绑定转移、摘要、旧协议兼容；验证 CLI 全能力、七天查询、Web 三分类
键盘与移动布局。提交前 make check，合并前按 AGENTS.md 独立 review 与 CI。


## 独立 review 与回归

第一轮独立 review 的四项意见全部采纳：托管执行同步必须保留 pending native
receipt 的未知占用；未绑定摘要也记录生命周期供后续绑定纳入；重绑定原子转移
活动摘要归因；所选分组独立于列表分页读取详情。补充了对应回归与手机/桌面
浏览器验证。另覆盖最小预算下串行准备摘要借用空闲负责人预留、归还以及精确
原生进程关闭范围；借用时阻止负责人并行开始 turn，不改变责任或租约。
