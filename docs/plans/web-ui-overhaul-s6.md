# S6 手机、性能与巡检实施计划

Refs: D132
Plan: S6

1. 复核手机聊天标题、输入提示、触控尺寸与安全区；详情及短暂弹层隐藏标签栏，保持导航、草稿、队列与焦点合同。
2. 主对话继续常驻，其余路由采用 lazy 与轻量 Suspense 骨架；核对构建入口大小及离线 shell 资源清单，独立提交等价拆包。
3. 新增自包含 UI 巡检夹具，覆盖全部路由、三种尺寸与深浅主题，检查标题、页面宽度、控件文字、侧栏及标签栏几何与控制台；接入 package script 和 CI。
4. 决定问题重复标题时使用原消息首行作为收件箱摘要，补充单元测试；服务端自有决定问题和选项改为中文，保留原因码、协议字段、决定种类与选项 ID。
5. 串行运行分片门禁及指定 Go 包测试，保存仓库外截图和日志；完成后更新主计划进度及 D132 状态，不执行完整 make check、不 push。

不新增依赖，不修改生成 API、迁移或业务合同；仅在本分支工作，独立 review 与最终验收由协调者执行。

## 文案合同说明

- 服务端内建选项字符串同时是回答 ID 和 Effects 键，没有独立 label 字段。按协调者确认，保留其原始字节；服务端问题和原因说明改为中文，Web 映射全部内建选项为中文，并从 Go 源码枚举选项集合验证映射完整性。不新增协议字段或改变决定种类。

## 回归同步修正

- 手机主操作统一使用触控高度，决定低高度探针按触控 token 核对尺寸，保留安全区、可达性及任务控制断言。补齐旧原生表单的主按钮高度。
- 路由拆包后，手机筛选助手先等待看板标题，更多导航探针先等待实际导航容器；避免将尚未挂载的路由误判为桌面布局或空导航，不增加超时或删除业务断言。

- 浮动跳转改为触控高度后，原 46px 的最小对话视口不足以容纳按钮及底部间距；手机视口下限同步保留按钮、上下间距和安全区，继续由既有跳转边界与低高度可达性探针约束。

## 实施说明

- 保留常驻聊天工作区与会话状态，非聊天页面按路由加载；Issue 阅读状态及发布横幅独立于详情模块，避免静态引用拉回整页。共享第三方模块单独拆包，离线 shell 缓存所有构建资源。
- 巡检使用隔离夹具覆盖看板各列、活跃及结束详情、任务执行、三类收件箱与资源页面；除计划尺寸外增加 320px 深浅主题，核对触控尺寸、末尾内容避让及 Sheet/Dialog 标签栏隐藏，原消息摘要仍保留原文。

## 独立评审修正：路由资源失效

- lazy 路由资源在发布后可能返回 404；在路由内容区内增加按路径变化重置失败状态的错误边界（不重建正常页面及筛选输入 DOM），显示中文说明及显式重新加载按钮。侧栏、标签栏和常驻聊天不进入边界，不自动重载或改变草稿、队列与业务合同。
- 单元验证正常内容及失败展示；巡检在新浏览器上下文拦截更多页 chunk 为 404，核对边界、外壳和聊天原 DOM／草稿仍保留，换页可用且手动重载恢复。串行执行 s6-r2 门禁。
