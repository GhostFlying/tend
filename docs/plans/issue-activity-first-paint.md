# Issue 讨论与进展首屏

现有活动读取按账本位置分页，但会为每个回合读取和编解码公开工具详情及回复中的工具记录。重连时，Web 还会按页重读整个已读范围。

1. 在现有活动接口增加可读投影。按稳定位置读取最近 50 条活动，用响应字节预算提前结束分页。读取用户消息、Agent 正文、关键状态、成果及过程的状态和时间，通过原回合接口按需读取工具输入输出。保留原接口投影及原详情权限。
2. 在可读投影上用账本水位增量合并，以原位置插入新出现的活动，并替换有变化的回合或移除撤回记录。用同一位置游标读取更早历史，保持阅读锚点及展开状态。
3. Web 先呈现正文，再空闲预取有限的最新和附近回合，展开时复用请求。失败允许显式重试，切换 Issue 取消旧请求。已展开的具体工具记录继续使用稳定 ID。
4. 验证正文和过程游标、回合增量、撤回、历史并发、预取请求复用与取消。用同一浏览器条件测量 PR #351 的重记录和轻量 Issue 的正文可读时间、过程展开耗时、活动条数及首屏字节数。
