# Web Chat 可见消息分页

当前 Web Chat 同时读取普通消息页和按回合分组的 transcript。后者串行等待队列，并为每个回合加载工具记录；普通消息页还可能为找停止目标回扫多页。Web SSE 为工具事件附上完整记录，并触发队列和 transcript 重读。用户打开 Chat 时，先看到最近可见消息，再按需要向前翻页。

- Chat 历史在 SQL 分页前筛选消息，以原消息序号保留向前、向后游标。保留所有者和 Agent 可见消息、正式组合结果和开放的选择。内部触发通知、过程、工具和原始参数继续从既有 Issue 详情或诊断入口读取。
- Web SSE 使用同一可见性规则，沿原账本序号重连。Issue 活动读取可接收所属会话和事件标识以刷新原详情。内部回合的状态变化只刷新所属会话的控制信息。隐藏事件推进重连水位。
- Chat 加载一页历史，发送队列独立读取。队列投影用运行中的原消息标识提供停止目标。恢复原停止操作只读消息状态，沿原请求不重复提交。发送回执、附件、撤回、选择均沿现有入口。
- 用实际 HTTP 历史和 SSE 从同一固定数据集比较请求、字节和串行轮次。覆盖工具密集、当前输入超出首屏、双向分页、重复和断线重放、决定和工具原件访问。用浏览器确认实际首屏及停止请求。

独立审阅后的修正：历史在 SQL 分页前排除已撤回输入，实时只发送原消息 ID 的移除事件，保持会话和账本游标。活动回合同时提供是否源于真实用户输入，Issue 详情据此显示发送或加入队列。上下文使用量入口保留轻量数据，Compact 历史及各会话的执行记录按需从诊断页读取。性能对照的请求范围为 Chat 历史与队列路径。
