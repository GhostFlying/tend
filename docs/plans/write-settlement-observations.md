# 记录领取刷新和轮次结算的分阶段耗时

用现有慢写观测拆开 `runner.claim` 中的暂停续行、外部等待和 Issue
manager 刷新。在既有事务和业务顺序内计时，记录各步查出的工作条数，
对比空领取与代表性回执和外部等待场景。总阶段仍保留，含子阶段。

为 `SettleOpenTurns` 的同一写回调分别计时。阶段包括标记待对账的原生
回执、关闭开放轮次并结算消息状态、中断工具调用、关闭输出消息以及
结算可修复的逻辑轮次。记录查出的实体条数。从现有领取、暂停、外部
等待和 Turn 入口重跑回归，验证未确认的回执仍阻止恢复，租约释放仍
要求实际停止。没有证据归因到具体慢操作时，保留现有 SQL 和状态变更。

阶段名称为固定集合，处理条数仅为聚合诊断数据，日志沿用现有慢写
阈值。阶段时长是包含子阶段的墙钟耗时，不能跨层相加。
