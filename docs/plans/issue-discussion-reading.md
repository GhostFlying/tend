# Issue 正文与收尾阅读

读者在当前 Issue 内看到目标、当前责任、结论与依据，再从讨论读回相关输入和公开回复。复现边界包括已关闭且没有进展摘要的 Issue、已取消但留有旧部署计划的 Issue、独立发布和带精确回复关系的负责人消息。原有事件、权限、Main 路由、消息入账、原生接收与终态职责保持各自的事实来源。

1. 在详情正文优先展示正式收尾、依据与取消状态；活跃责任展示有效进展和下一步。计划阶段按原状态展示。已有收尾缺失保留缺口。
2. 在公开活动中显示可证实的回复对象，独立发布不推测父消息。按后台事件性质折叠例行记录，保留实质回应、人工决定、失败、暂停与未知。历史进展只使用对应时刻有记录的证据。
3. 通过组件、读取与浏览器用例验证上述样例、折叠和读回；保留分页、锚点、历史作者和公开过程故障后的正文。按最终差异运行受影响检查和独立审阅，部署由统一发布进行。
