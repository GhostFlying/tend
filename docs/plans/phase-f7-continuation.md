依据阶段 F 的 F7、D69–D72，保留已有会话、待决事项和实时读取实现。

1. 补齐按 project 分组的任务列表与 host 概览。
2. 补齐任务详情：状态、评级、控制模式、工作区和分支、目标与验收条件、动作、run、产物、验收结论和日志；控制操作沿用带版本校验的 owner API。
3. 对照既有设计稿检查桌面、平板和手机布局，验证任务控制、待决回答与会话交互。
4. 运行 `make check`、差异检查；浏览器截图保存在仓库外。浏览器验证使用 Playwright，因为当前没有 Browser 插件。

真实 traex 与 Mac/iPhone PWA 验收由阶段 F8 单独记录，本计划的浏览器模拟不代替真机验收。

## 实施记录

- 任务按 project 分组，选择任务或回复中的任务标签可打开详情；补齐主机容量概览。
- 详情展示账本中的规格、工作区与分支、动作、run、产物、验收结论和日志。暂停、恢复、接管、交还和取消均带控制版本；取消先在页面内确认。
- 日志按游标增量读取；单次读取有上限，未读到末尾时明确提示并允许继续读取，不把较早日志误称为最新。
- 手机可以切换主题、在待处理页看到操作反馈。停止回复的回执未知时保留禁用状态，跨页面重载保留这个限制，直到消息结束或操作被明确拒绝。
- 本地使用生产构建和嵌入式服务端验证 CSP、service worker 外壳缓存与离线重新打开；桌面、平板和手机尺寸的交互检查使用模拟任务数据。
- F8 的真实设备、多端会话和真实任务验收仍由阶段 F 的验收流程负责。
