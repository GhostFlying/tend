# 共享审阅按任务规格与执行代次识别报告

Issue 短号 PR 的原审阅 Task 更新规格后从新规格的第一代重新执行。旧规格和新规格的第三代有不同 Run，但共享审阅的 recheck 仅比较 Task 与 generation，拒绝登记新报告。

- 比较冻结的 Task、规格版本和执行代次。补充报告使用自身冻结的规格版本。缺少历史字段且可定位原 Run 时，从其不可变动作补齐比较所需的值；结果仍不明确时保持原判重行为。
- 同一 Run 或验收仍不可重复登记。登记继续核对原审阅人、实际报告和候选，旧轮次在原记录中保留。已拒绝的登记可通过正常 recheck 登记适用候选的真实报告。
- 回归通过正式命令创建和登记审阅，继续原 Task 并更新规格，执行相同代次并登记结果。覆盖原审阅报告和历史补充报告，检查同一 Run 的重复登记仍被拒绝。
