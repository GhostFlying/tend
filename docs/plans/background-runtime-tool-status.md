# 后台运行时工具状态修正（D114）

真实闭环验收发现：owner 会话列表按托管配置设置 `runtime_available`，而主 Agent 的同名查询直接返回存储投影，布尔零值被解释为后台运行时不可用。后台已执行并回传时仍出现误报。

实施：

1. 托管主 Agent 的会话查询明确返回后台能力可用，遵循 D114 的托管启动即启用后台能力约定。该字段表示能力已配置，不代表某个会话正在运行或上下文已经就绪。
2. 保留现有会话状态、排序和分页，以及非托管身份拒绝规则；不改变 runner 协议、数据库或调度。
3. 增加工具调用回归测试，验证无会话时也不会误报不可用；执行 `make check`、独立 review 和 CI，再合入并更新服务端产物。
4. 部署保持当前新实例、验收数据和网络身份，不再次清空业务库。
