# 临时CI App成本对照

Refs: D151。当前候选在本地完整检查有收益，但不同runner的两次CI App耗时相反；不从本机结果推算CI收益。本分支只用于workflow_dispatch诊断，不作为日常门禁或合入内容。

在同一ubuntu runner、同一路径、同一工具链/CPU配置顺序运行`7970ab96`与`1c2da88a`的完整App分组；各自预热构建，固定四分片，count=1关闭测试结果缓存，保留race和全部1032个顶层根。记录CPU型号、CPU/配额、GOMAXPROCS、源码SHA、准备、墙钟、累计CPU、每分片原生JSON及完整/失败状态。

若候选墙钟比基线慢超过5%，再在同机同源码上执行GOMAXPROCS=1的候选，检验四个App进程的CPU过量并发；否则不额外运行此分支。该配置只用于对照，不自动修改PR。失败保留并停止收益判断，所有记录上传为临时artifact。无生产部署、依赖增加、共享基线或夜间任务。
