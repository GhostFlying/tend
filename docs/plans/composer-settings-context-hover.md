# Composer 选择器与上下文圆环交互

依据 D73、D89、D111，修正 Web composer 的交互，不改变设置写入、请求去重、上下文采样或 compact 语义。

## 实施步骤

1. 使用现有 Playwright fixture 复现选择后的文字变化，检查保存状态替换思考强度文字的过程。
2. 模型与强度始终展示服务端确认的值，保存、待核对及错误状态用独立提示表达，避免在值的位置交替显示状态文字；保留键盘导航与错误恢复入口。
3. 上下文圆环只展示环形用量，百分比保留在无障碍名称和详情中。鼠标悬停或键盘聚焦可查看详情；指针可以跨过间隔进入详情操作，离开后关闭。保留触屏点击与 Escape 关闭。
4. 用桌面及手机视口验证选择、悬停、详情内操作、键盘和触屏兼容，运行 Web 检查与仓库要求的检查，记录验证边界。
5. 独立 review 发现的交互边界纳入回归：悬停打开且输入框仍聚焦时 Escape 也能关闭；从详情移回圆环后继续保持展开。关闭延时同时检查指针和焦点，hover 关闭不抢走原输入焦点。
6. 导航切换时关闭详情，返回对话后由用户重新打开；同步现有 decision-layout 回归，避免沿用旧版弹层自动恢复展开的断言。
7. Escape 优先交给当前聚焦的控件；hover 详情的关闭监听在冒泡阶段响应未被处理的 Escape，不拦截模型菜单的返回/关闭，也不阻止外部输入控件的默认行为。

## 验证结果

- `pnpm --dir web check` 通过：类型、lint、格式、257 项单元测试及构建。
- `pnpm --dir web test:agents` 通过：覆盖 1505×1045、1280×900 和 390×900；保存期间文字与位置稳定，圆环无文字，hover 不抢焦点，指针可进入详情并返回圆环继续悬停，离开关闭，hover 时 Escape 保留输入焦点，键盘打开与 Escape 返回圆环焦点、触屏点击及原有后台会话操作均通过。
- `git diff --check` 通过。
- `pnpm --dir web test:decision-layout` 通过，覆盖更新后的导航关闭与重新打开详情，以及原有受限布局、缩放、键盘和故障恢复场景。
- `make check` 全部通过，包含协议、Go 格式、vet、staticcheck、全量 Go race 测试及 Web 检查。
- 按仓库要求运行独立 review，采纳并修复 hover Escape、返回圆环、导航关闭断言及聚焦菜单的 Escape 优先级问题；最终复核无可操作意见。PR 的 CI 全部通过后，以 rebase 方式合入。
- 浏览器验证使用本地合成 API fixture 与 Chromium；不代表线上部署或真实 harness 的运行验证。
