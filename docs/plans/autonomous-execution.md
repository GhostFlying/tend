# Agent 自主执行、短停机更新和分层验证

Refs: D219–D225、D227–D229、D252。本文记录实现前已确认的完整重构范围。

## 目标与不变量

业务规划、协作、是否审阅和完成判断由责任 Agent 决定。代码仅维护身份、明确授权、
对象归属、并发版本、租约、实际进程和不可重复的外部副作用。人类、仓库与外部平台
明确要求的检查仍执行。Agent 自选审阅可调整，不冻结为永久业务义务。

Issue 保存目标、约束、责任和准入；Task 保存持续协作目标及结果；Run 保存一次执行；
Artifact 保存不可变成果与审阅；Delivery 保存外部目标、授权、动作身份和观察。
正常执行与恢复共享事实及转换，不通过新的业务 Run 或模型轮次读取历史收据。
未知操作仍按原身份对账。事务只提交直接状态、事件和待投递；投影按相关范围更新。

Session 是可替换的执行上下文。相同目标沿同 Task 追加 Run，新会话从持久记录重建；
配置适用时复用，工具表不能原位更新或 thread 明确不可用时新建。旧请求结果未知时
不得重发。所有角色共用执行和会话规则，不要求旧会话恢复或模型摘要才能新建。

## 批次与验收

- [x] B2：统一执行与 session；精简成果、审阅、交付和恢复生命周期及公共入口。
- [x] B3：server 预下载并通过现有认证链路分发，节点准备完成后才停止写入。
- [x] B4：局部停止、必要快照与迁移、候选就绪、持久提交、恢复接单；单 runner 可升级。
- [x] B5：独立新 installer 的本机强制恢复，不依赖旧服务响应或旧 updater 状态可解析。
- [x] B6：删除旧策略和重复测试，补全业务/会话/分发/安装/强制恢复闭环，启用影响 CI。
- [ ] B7：最终验证、独立代码审阅、完整发布和切换演练；实际部署另按明确授权执行。

每批更新代码、设计、CLI/工具/API/Web 契约及测试。删除断言须记录失效原因或承接
测试，不以 skip 代替删除。生成代码通过原生成器更新，历史迁移只追加。

## 更新关键路径

准备：固定完整发布集，server 下载并暂存，节点通过现有 Tend 链路获取并校验；
配置、磁盘和迁移检查在接单期间完成。缓存按内容复用，不重新选择移动的 main。
切换：关闭必要准入，停止真实写入者，必要数据快照/迁移，替换并启动，确认实际
候选就绪，持久提交后恢复。收尾：session 恢复、业务对账、通知、归档和清理。

停机期间不得下载、构建、运行测试、调用模型、等待固定心跳次数或其他无关业务。
相同组件不替换；单 runner 不要求备用主机。只有存储迁移需要数据快照；配置变化
保存原配置；纯二进制更新不复制全部业务数据，不重扫不可变历史原件。
实际进程、产物、配置和存储就绪握手代替固定健康采样门槛。提交后由正常监督负责
持续健康，不恢复旧业务数据。提交前回滚仍要求真实停止、可恢复数据和没有新业务。

新增本机入口 `tend upgrade recover --release <bundle> --config <config> --force`，
使用新发布的 CLI/installer。首次生成并保存恢复身份，重试沿原身份读取事实。
本机查询不依赖旧服务。正常自动升级不自行提升为强制终止权限；明确调用授权本机
目标范围的强制停止。停止监督和确属本实例的写入者、取得独占权后替换。旧状态
无法解析时原样保留，使用统一新安装记录继续；数据不可读不因 force 被忽略。
不要求旧升级取消、旧服务健康、manager park 或旧服务再次授权。业务未知保持未知。

## 测试与选择

L0 静态/纯逻辑；L1 组件/契约（真实存储，保留 race）；L2 确定性跨组件完整流程；
L3 真实进程/systemd/harness/网络。层级不允许跳过受影响的昂贵测试。
沿现有 impact 和 test-plan 自动发现根；拆分任务、会话、交付、更新流程的依赖。
PR CI 从影子模式切换到确定计划驱动；main/release、协议、迁移、工具链、检查基础
设施及未知影响保留全量。必要作业缺失、失败、取消或跳过不能当成通过。
本地保留缓存与自动 CPU 预算；新鲜回归才强制 count=1，不重复执行不变候选的 full。
发布复用 CI 产物，安装只验证产物与实际安装就绪。

必须覆盖：自主完成/可选审阅/明确要求审阅；丢收据后外部动作只发生一次；会话
复用/替换/重启/未知发送；无外网 runner 经 server 取包；单节点升级恢复原任务；
旧服务和 updater 均不可用或状态不可解析的外部恢复；阶段重启、停止失败、进程
身份变化、回复丢失；纯二进制更新不备份全库，停机期间不调用网络和模型。
沿真实公开入口驱动，模型和外部服务默认替身，suite 内产物只准备一次。

退役测试：旧协议与对象适配、默认强制审阅/永久冻结、提示词逐字匹配、重复阶段
穷举、全局 drain 与备用 runner、固定健康心跳。身份/独占/unknown 断言保留或迁移。

## 首次切换

本次允许不保留旧协议并行运行，整体提升通信版本并删除活动兼容适配。
停止旧接单和实际执行，归档旧数据库、原件、journal 和 updater 状态，保留配置及
主机身份，整套替换组件；默认新的业务数据库，不自动重放旧任务、不删除原件。
后续普通更新保留业务数据并执行必要迁移。记录准备、停机、迁移和收尾实际时间。

## 实施记录

B1–B6 的实现与回归已落地。物理 stop、外部等待和暂停共用关闭事实；数据库事件
重放与原生收据读取均附着原责任，不创建业务执行。按需开启独立审阅时，在同一
事务补全审阅责任并保留原实现 pin；Issue 上显式的 Agent 选择由新 Task 继承。

独立审阅发现并修复：人类门槛来源丢失、未提交安装的取消准入、工具表变化时
恢复旧会话、终态数据库事件无重放入口、后加审阅缺少执行契约、旧启动 journal
阻塞外部恢复、交叉编译缺少嵌入资源。对应故障用例保留；测试退役见 `docs/testing.md`。
B7 的完整检查、最终审阅和真实发布包演练完成后记录最终结果，部署仍单独授权。
