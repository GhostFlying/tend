# 侧栏工作项与最近完成任务（D90）

用户确认侧栏以工作项为日常入口，执行任务留在工作项详情和独立执行记录页面，避免两套列表重复展示。

1. 移除侧栏“执行任务与记录”展开区及按项目重复展示的当前任务列表。
2. 按用户批准的设计稿展示三个工作项，提供查看全部入口；其后保留最近三个已完成任务，显示标题、主工作项、真实完成时间，点击查看结果。
3. 完成时间由 task.completed 事件派生，新增可选 owner API 排序参数，最近列表按完成时间排序；修改旧任务信息不影响顺序。无完成时间的历史数据不伪造时间。无需迁移或 runner 协议变更。
4. 最近完成之后保留次级“全部执行记录”入口。资源和设置沿用现有功能。删除不再使用的任务概览组件，保留独立执行记录页。
5. 更新 D90 的展示约定，补充排序/归属/分页验证，运行 make check、浏览器布局和导航检查与独立 review，经 PR 和 CI 合入后发布。
