# 主会话选择器对齐参考设计

依据 owner 对模型/思考强度选择器的反馈，修正 D73 的呈现方式。参考项目的 ModelSelect 与输入框工具栏：紧凑的模型名和 effort 联合入口、28px 无边框胶囊、上弹两层菜单、次级 effort 字色、当前项尾部勾选。

## 实施

1. 将入口放到输入框底部工具栏、发送按钮旁；正常状态不再单独显示两个原生 select 或常驻一整行说明。辅助说明放入菜单，保存中、目录不可用、未知回执和错误仍须可见且能核对/重试。
2. 复用现有设置状态与 API，根菜单分别进入模型和思考强度列表；选择后保持现有服务端生效语义。无 effort 能力的模型不提供可操作的 effort 列表。
3. 沿用现有 CSS token，菜单浅/深色主题一致；长模型名截断，手机边界不溢出；键盘支持打开、方向键导航、Escape 返回/关闭、关闭后还原焦点，外部点击与 Tab 离开关闭。
4. 浏览器验证桌面及手机尺寸、浅深色、长名字和长目录、模型/effort 保存与共享、故障状态和焦点。Browser plugin not available，使用现有 Playwright；不引入新依赖、不使用 orca。
5. make check、独立 review、CI、rebase 合入与部署，保存截图和独立读回；不修改模型选择的后端语义与数据库。
