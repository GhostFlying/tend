仅修复底导航角标的图标锚点、行高与视觉边界；待 owner 处理的计数不改为未读数，
不修改 read/archive、Attention 或请求语义。视觉大于99时显示99+，辅助说明保留完整数值。

1. 复用既有隔离 API/真实客户端浏览器复现方式，先保存原版几何与截图，再修复。
2. 独立图标锚点使角标位于右上方，显式行高与背景隔离，保留整行点击区域。
3. 在320/390宽、浅深色、0/1/2/10/99/100与分页more、大数字下验证：角标不遮图标
   和标签、不越出导航链接，不产生横向溢出；active/inactive及滚动后点击仍进入收件箱。
4. 运行相关Web检查与规定独立review；完整检查与CI在仓库既有并行窗口中执行。
   只交付PR，保持生产关闭和部署集中安排。本修复不改变设计决策。
