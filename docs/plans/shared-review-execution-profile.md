# 共享 PR 审阅的实际执行配置校验

状态：维护批次正式审阅发现，按 D186 修复；仅增加可选 round 响应字段，保持 N/N−1 wire 兼容，不改变默认 Agent 配置。

## 问题

关联任务明确要求正式 reviewer 的模型或思考强度时，当前绑定逻辑只比较双方非空的 spec 字段。独立审阅任务省略字段后使用 Agent 的正常默认配置，可能绕过关联任务已经冻结的要求，最终结果读取也仅核对 reviewer 身份。

## 实施

1. 在绑定 reviewer 时解析实际已冻结的 run/责任合同；尚未执行时使用所选 Agent 的真实配置检查兼容性。省略 spec 字段仍表示使用合法默认配置，不要求所有调用者重复填写模型和强度。
2. 开始审阅时以可选对象冻结本 round 的明确要求，空数组表示明确无额外要求，缺对象仅用于历史读取。读取结果时以真实 run execution pin 核验本轮冻结要求；原验收导入和聚焦补证使用同一判定，不以当前 Agent 配置代替历史 run。模型与强度纳入当前需求 digest；本轮真实结果入账与当前适用性分开，后来的新要求不会卡住旧结果，不能证明符合当前要求的历史结果保持 `Valid=false`。
3. 保留原 Task/spec、review 历史、执行配置和失败。不满足明确要求的结果保留真实记录，但没有当前合入效力，沿既有有界复查恢复；不自动改写 Agent、模型、强度或授权。需求 digest 同时保留正式 reviewer 的 category、identity 和 runtime 选择，不纳入 implementation 选择，不增加 category 冻结机制。
4. 增加聚焦回归：省略字段且默认不匹配时拒绝；匹配默认仍可使用；模型与强度分别生效；实际历史 run 不匹配时不能导入通过。执行受影响测试，不运行完整检查或新 review 模型。
