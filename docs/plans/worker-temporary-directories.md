# Worker 临时目录与证据保留

## 问题

worker brief 和 Git 工作区指令要求全部临时文件位于任务 scratch。
scratch 的绝对路径可能很长，把它直接用作 `TMPDIR` 会超过 Unix socket
的路径上限。短符号链接又不能满足要求真实目录的测试，导致普通环境适配
升级为外部维护请求。

## 实施

1. 修订共享 worker brief 和工作区规则：下载、报告、实验副本与需要提交的
   证据仍使用 scratch；工具、构建和测试的运行时临时文件允许使用 Agent
   自行创建并清理的私有系统临时目录，必要时选择短的真实 `TMPDIR`。
2. 同步已有运维与验证文档，移除强制 `TMPDIR=scratch` 和符号链接别名建议。
   scratch 只是提交前的暂存位置，正式保留仍由原有文件提交回执证明。
3. 对实现与验收两角色、默认布局与现有 Git guide 检查一致的提示语，保留
   验收只读工作树、下载位置及原文件提交语义。
4. 运行受影响测试、完整 `make check`、独立 PR review 与所需 CI；合入后
   按原配置受控部署。已有任务可经原问题说明临时目录用法并继续原责任。

## 边界

不修改 sandbox 的符号链接检查、工作区或 scratch 分配、不增加权限审批、
不改变 runner 配置、模型或并发预算，不通过跳过检查消除路径错误。

Refs: D205。
