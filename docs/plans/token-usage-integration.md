# Token 用量融入主界面

依据 D70、D117，沿用现有只读统计接口与原生 dialog，不改变采集、存储或协议。

## 实施步骤

1. 统一资源与记录导航：桌面三条整行入口共用样式，主机状态独立；Issue 手机页直接打开资源 dialog，执行记录继续可达。
2. 用量默认全部历史；范围、模型与刷新集中；主摘要、时间未知摘要、时间分布、分类、请求明细、覆盖说明形成连续层次。
3. 严守字段独立 known、历史包含未知时间子集、时段不包含未知时间、缓存不重复加总的语义；模型选项合并但数值不合并。处理同键旧数、换键失败、请求交错和 revision 回退。
4. 使用隔离合成 API 验证桌面、窄屏、暗色、键盘、共享单 run、分页、失败恢复与语义边界；保存相同 fixture 的改动前后真实截图及离线预览。
5. 运行 make check，完成代码提交；独立正式验收由后续 reviewer 执行，不合并或部署。

## 验证矩阵

覆盖 N1–N3（导航、手机、焦点）、S1–S6（历史、时段、混合、缺失、零、空态）、F1–F3（模型、周期、交错）、D1–D2（分页、详情）、E1（读取失败）、C1（覆盖与冲突）、V1（响应式）、R1（单 run）及 B1（检查与交付）。浏览器截图、报告及复现包保存在仓库之外；不得包含真实凭据或生产数据。
