# Web 已注册仓库只读展示

依据 D30、D58、D70：仓库是账本登记资源，和 project、任务 mount、checkout 不同。

## 实施项

- R1：将全量仓库及未退役主机的服务对应关系提到 views，共用 repos_list 与 owner GET /api/v1/repos；owner 返回仅逻辑名、退役标志和主机 ID。保留工具原有候选、模板及主机能力语义，Web 不展示候选或敏感配置。协议 schema 生成客户端类型，不变更 runner 通信。
- R2：桌面侧栏执行主机附近、手机看板资源区提供“已注册仓库”与真实总数。共用原生 dialog，滚动列表包含全部启用和退役登记，无主机明确提示；关闭、Escape、背景点击返回入口焦点，长名称换行。保留现有设置和主机入口，不新增底栏。手机资源列表各自滚动，外层看板页面可纵向滚动并给任务区保留最小高度，双列表展开也不压缩任务卡片。
- R3：独立读取状态保留最近成功数据，首读、打开、刷新、重连及恢复前台重新读取。失败和断线标记旧记录，未知总数不显示为零；AbortController 与读取代次阻止旧响应覆盖。列表不受项目筛选影响。
- R4：覆盖认证、只读、安全字段、多个启用/退役/无主机/多个主机及工具一致性；覆盖读取失败、重试、空列表、并发旧响应。用真实浏览器验证 390、430 与桌面布局、滚动末项、焦点和导航，交付通用数据截图；完成 make check 与独立 codex review 后原子提交、推送、创建 PR，不合并或部署。
