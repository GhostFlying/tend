# Agent 命名约定（D123）

## 目标与范围

复用 `local_id` 作为具体 Agent 的稳定 slug，`display_name` 作为面向人的名字。定义者可以是用户，也可以是负责编写配置的 Agent；命名在定义时完成并写入配置。Category 继续表达跨 runner 的工作分类，CLI、model、effort 和 runtime 独立配置。

本次补充定义指南、设计依据和字段注释，不增加配置字段、自动命名服务、创建入口或 UI，不修改已部署定义和历史身份。

## 实施顺序

1. 增加当前配置编写指南，说明命名责任、建议格式、重名处理、身份边界和完整示例。
2. 在 D123 与原配置计划中链接指南，在配置字段旁说明 slug 和显示名的语义。
3. 核对指南与现有 decoder、ID 校验、公共投影及本机接受流程一致；运行仓库要求的检查并提交 PR。

## 兼容与验证

新定义推荐小写英文、数字和单个连字符分隔的短名。现有校验接受的大小写、下划线、点等 ID 仍有效，不收紧本地或 runner wire 校验，不提升格式、存储或通信协议版本。

不从显示名、模型或 category 动态推导身份，不在 reload、启动、同步或升级时补名或改名。显示名变化仍按现有定义 revision 和显式接受流程发布；旧任务和运行继续使用冻结身份及版本。已有 slug 的变更需要显式身份交接，历史引用保留。
