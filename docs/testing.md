# 测试分层与修改成本

Refs: D252。层级描述验证的边界和运行成本，不是按测试数量分配配额。

| 层级 | 边界与例子 | 运行方式 |
| --- | --- | --- |
| L0 | 格式、生成文件、能力目录、纯状态转换、影响选择器 | `make go-check`；纯函数测试仍由所属 Go 包执行 |
| L1 | App+SQLite、runner journal、API/CLI 契约、fake updater 进程边界 | 受影响包的 `go test -race`，保留包内全部用例 |
| L2 | 确定性 server→runner→harness 完整业务、真实 HTTP、断连/丢收据/重启 | `internal/e2e` 与 production assembly；依赖图受影响时必须包含 |
| L3 | 真 systemd、真实 harness/网络、外部环境 | `integration` build tag，显式 `make it` 或目标包集成测试 |

Go 包尚有混合层级的用例，选择器以真实包依赖和跨包测试根为准，不靠目录标签
或正则切掉昂贵断言。L3 是唯一显式环境层；测试应记录依赖和清理自身资源，不能
占用正式服务。普通测试不联网、不调用模型。端到端测试只替换外部边界，尽量经
公开入口驱动业务转换，不能把目标终态直接写入 fixture 后宣称验证了完整路径。

本地先运行 `make test-plan` 查看实际 diff 的包含/排除理由，`make check`
执行该计划；需要完整新鲜基线时运行 `CHECK_MODE=full TEST_COUNT=1 make check`。保留自动 CPU 预算，
不在外部再并行启动另一套 full。PR CI 使用同一选择器；main/release、协议、迁移、
生成器、工具链、检查基础设施和无法判定的改动走全量。计划绑定源码和基线；修改
后重新生成，不能复用另一个候选的绿色结果。CI 聚合验证所有必要作业的终态。

D252 的退役与承接：

| 删除或改写的测试 | 原因 | 承接契约 |
| --- | --- | --- |
| runner v3 通信适配和旧窗口准入 | 首次冷切换只接收协议 5 | current protocol 明确拒绝旧/未来代，不分配 Run |
| upgrade_cutover、备用节点和全体正常 ACK | 单实例安装不依赖第二个节点 | 单 runner、预下载、逐机安装与实际持久回执 |
| 默认必须审阅、不可调整的自选审阅 | 审阅默认自主，明确门槛仍保留 | 默认完成、主动审阅、人类要求不能由 Agent 撤销、原 Task 变更审阅 |
| 固定两次心跳 | 不是安装正确性的事实 | 进程/产物/存储就绪及 durable commit，提交前禁止接单 |
| 关闭后的 receipt reader 再领取 Run/租约 | 历史读取不执行业务 | 原 Run 心跳读取、丢回复重试、无模型/新 Run/新租约、非终态保持 unknown |
| generic_receipt_binding 的旧 leased reader 组合 | 无原生待确认操作的合成 reader 已退役 | 原执行身份绑定、跨 Issue 隔离，以及真实 runner 心跳的历史读取闭环 |
| 升级中额外领取/关闭 receipt reader 的阶段组合 | 历史读取不再创建进程或租约 | 原 Run 的真实关闭及心跳读取；原物理 close 的 unknown/重启/取消测试继续保留 |
| 旧工具表必须成功 resume | Session 是可重建缓存 | 新工具表从账本重建，未知原请求不得重发 |

应保留请求身份、真实进程退出、独占、授权范围、数据迁移、不可重复副作用和
unknown 的故障测试。提示词文案测试只检查必要能力/输入契约，不逐字固定表达。
发布复用验证过的不可变产物；下载、构建和测试全部在停机前，安装只验证实际目标。
Go 修改需要交叉编译时，CI 单独构建嵌入资源；没有 Web 影响时不运行前端单测或浏览器回归。
